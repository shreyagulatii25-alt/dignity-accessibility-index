# Dignity Accessibility Index (DAI) Dashboard

Interactive academic prototype accompanying the project **The Invisible Infrastructure of Dignity**.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, and this README.
3. In Streamlit Community Cloud, choose **Create app** / **Deploy an app**.
4. Select the repository, branch `main`, and file `app.py`.
5. Deploy and copy the public app URL.

## Integrity note
The built-in A–E scenarios are illustrative prototypes, not real facility audits. The DAI evaluates facilities, not people. The index is a prototype and is not a validated national index.
